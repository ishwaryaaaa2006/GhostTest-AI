\# 👻 GhostTest AI



\### AI-Driven Automotive Software Validation Platform



GhostTest AI is an AI-assisted automotive software validation platform designed to discover, simulate, analyze, and prioritize high-risk driving scenarios that conventional testing may miss.



The platform combines scenario simulation, AI-assisted risk analysis, regression-oriented testing, driver monitoring, and safety fusion into a unified validation dashboard.



\---



\## 🎯 Project Objective



Modern automotive software systems must be validated against a large number of possible driving conditions.



GhostTest AI aims to assist this process by:



\- Generating and analyzing automotive test scenarios

\- Simulating Automatic Emergency Braking (AEB) behavior

\- Identifying potentially high-risk scenarios

\- Monitoring driver alertness using computer vision

\- Combining driver risk with vehicle and AEB risk

\- Supporting regression and scenario comparison

\- Providing actionable validation insights through a web dashboard



\---



\## ✨ Key Features



\### 🚗 Automotive Scenario Simulation

Simulates vehicle scenarios using parameters such as:



\- Vehicle speed

\- Object distance

\- Visibility

\- Weather

\- Sensor delay

\- Road condition



The AEB simulation calculates values including:



\- Reaction delay

\- Delay distance

\- Braking distance

\- Total stopping distance

\- Safety margin

\- PASS / FAIL result



\### 🧠 Ghost Intelligence



AI-assisted scenario analysis provides insights into potentially important validation scenarios and their associated risks.



\### 🔥 Safety Fusion



GhostTest AI combines:



\- Driver monitoring state

\- Vehicle speed

\- Object distance

\- Visibility

\- Weather

\- Sensor delay

\- Road condition

\- AEB simulation result



to produce a combined safety assessment.
